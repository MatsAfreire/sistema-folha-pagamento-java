# Sistema de Folha de Pagamento em Java

Projeto desenvolvido como parte da disciplina de Algoritmos e Programação.

## Funcionalidades
- Cadastro de funcionários (Padrão, Comissionado e Produção)
- Cálculo automático de salários
- Validação de entradas (valores negativos e inválidos)
- Listagem de funcionários
- Menu interativo via terminal

## Tecnologias
- Java
- Scanner
- ArrayList

## Objetivo
Aplicar conceitos de lógica de programação, estruturas condicionais, repetição e manipulação de dados.

## Status
Concluído e testado com múltiplos cenários (validações, erros e fluxo completo).
